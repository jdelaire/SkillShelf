# SkillShelf 0.2.0

- New System prompts section in the sidebar. For each installed harness it shows what goes into the system prompt: instruction files and config keys, the vendor base prompt for the installed version, and live captures.
- Base prompts: Codex reads them from its local model cache. OpenCode's are fetched from GitHub for the installed version and cached. Claude Code, Cursor, Grok, Antigravity and Muse Code don't publish theirs, so those rows say so.
- Capture now runs Claude Code, Codex or OpenCode once in an empty temporary folder and records the request it would send. The run is sandboxed to a local listener with a placeholder key, so nothing reaches the vendor and no session is added to your history. Captures are saved under ~/Library/Application Support/SkillShelf/captures.
