# SkillShelf 0.1.3

- Muse Code support. SkillShelf shows the skills Muse loads, from its own folder and from the Claude, Agents and Codex skill folders it reads, using Muse's own skill list. Bundled Muse skills are locked, and Push to all harnesses links into `~/.config/muse/skills` when Muse can't already see a skill.
- The detail pane shows the skill's SKILL.md, rendered as markdown. Relative links and images open from the skill's folder.
- Switching harness clears the selection, so the detail pane no longer shows a skill from the previous list.
- Built-in, managed and third-party badges are easier to read in dark mode.
